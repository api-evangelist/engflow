# EngFlow

> EngFlow provides remote build execution, remote caching, CI runners, and a Build & Test UI that accelerate large-scale software builds for Bazel, BuildStream, Goma, Pants, Soong, CMake, and Buck2. EngFlow clusters expose a gRPC / Protocol Buffers API surface — the open Remote Execution API (REAPI v2) and Remote Asset API, plus EngFlow's own cluster, IAM, authentication, event store, result store, secret, and notification services (published in EngFlow/engflowapis). Backed by a16z.

This llms.txt was generated by the API Evangelist enrichment pipeline from the EngFlow catalog record (no provider-published /llms.txt was found on 2026-07-19).

## APIs
- [EngFlow Cluster API (gRPC)](https://docs.engflow.com/re/index.html): Cluster info, IAM, authentication, event/result store streaming, secrets, notifications; plus REAPI v2 and Remote Asset API.

## Specs (Protocol Buffers)
- [Cluster service](grpc/engflow-cluster.proto): GetInfo.
- [Identity and Access Management service](grpc/engflow-identity_and_access_management.proto): GetRole, CreateRole, DeleteRole, UpdateRole, ListRoles.
- [Authentication service](grpc/engflow-authentication.proto): Authenticate.
- [Event Store service](grpc/engflow-eventstore.proto): GetBuild, GetInvocation (streamed build events).
- [Result Store service](grpc/engflow-resultstore.proto): GetInvocation (streamed invocation).
- [Secret service](grpc/engflow-secret.proto): List, Get, Set, Delete.
- [Notification service](grpc/engflow-notification.proto)
